# lmline: charter

## Purpose
lmline: a Bash/zsh line-editing helper that asks an external language model for command
candidates and inserts the chosen one into the shell's line buffer. It executes nothing
unless the user explicitly asks it to.

## Rules
- Commit subjects: one plain imperative sentence describing the change; no internal
  identifiers.
- No private paths, credentials, hostnames or user data in public files (see PUBLISHING.md).
